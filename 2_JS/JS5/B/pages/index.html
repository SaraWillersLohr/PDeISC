¿Cómo funciona?

Este portal consume la API REST del Proyecto A para mostrar los alumnos registrados. Podés cargar los datos con Fetch o con Axios y comparar ambos métodos.

Flujo de consumo
  • Frontend: Esta página envía una petición GET al Proyecto A.
  • Fetch: API nativa del navegador para hacer peticiones HTTP.
  • Axios: Librería externa que simplifica las peticiones HTTP.
  • API REST: El Proyecto A responde con los datos de MySQL en JSON.
  • DOM: JavaScript renderiza los datos en la tabla dinámicamente.
