# NSJ3 — Resumen de proyectos P1..P6

Este archivo lista cómo ejecutar cada proyecto y los archivos clave por proyecto.

Ejecutar un proyecto

- En cada carpeta `P1`..`P6` hay un `package.json`. Para ejecutar:

```bash
cd P1
npm install
npm start
```

Puertos por proyecto (por defecto)

- P1 → http://localhost:3006
- P2 → http://localhost:3007
- P3 → http://localhost:3008
- P4 → http://localhost:3009
- P5 → http://localhost:3010
- P6 → http://localhost:3011

Sugerencia: abrir cada proyecto en una pestaña del navegador.
