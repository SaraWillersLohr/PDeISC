¿Cómo funciona este sistema?
  1. El usuario completa el formulario.
  2. Se ejecutan las validaciones.
  3. Se envía una solicitud POST a la API.
  4. Express recibe la información.
  5. La API guarda el alumno en MySQL.
  6. MySQL devuelve una respuesta.
  7. La tabla se actualiza automáticamente.
