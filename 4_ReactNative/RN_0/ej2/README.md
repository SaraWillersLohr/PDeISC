# Componentes de React Native

Aplicación de ejemplo hecha con Expo y TypeScript. Presenta componentes nativos importantes de React Native en tarjetas con una explicación, una demostración y un fragmento corto de código. Incluye diseño adaptable y modo claro u oscuro.

## Cómo ejecutarla

1. Instalar Node.js si todavía no está instalado.
2. En esta carpeta, ejecutar `npm install`.
3. Ejecutar `npx expo start`.
4. Escanear el QR con Expo Go o abrir la versión web con la tecla `w`.

La guía toma como referencia [Core Components and Native Components](https://reactnative.dev/docs/intro-react-native-components).
