Node.js + HTTP + FS

Ejercicio 2: componente que lee un archivo HTML desde el sistema de archivos y lo muestra en el navegador usando el modulo HTTP.

HTML servido desde el File System

Este archivo HTML ha sido leido desde el sistema de archivos (File System) y servido mediante el modulo HTTP de Node.js.

Servido Correctamente Modulo HTTP Modulo FS

Como funciona este ejercicio

  • El archivo index.html vive en la carpeta pages.
  • El modulo lector.js usa FS para leer el archivo del disco.
  • El modulo servidor.js responde con HTTP y muestra el HTML.
