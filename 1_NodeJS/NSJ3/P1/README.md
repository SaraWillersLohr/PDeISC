# Proyecto 1 - Jugando con el DOM

¡Hola! Este es el primer proyecto. Aquí la idea es mostrar cómo podemos usar JavaScript para "tocar" y cambiar cosas en una página web sin tener que recargarla.

## ¿Qué hace este proyecto?
- Puedes agregar un título que dice "Hola DOM".
- Puedes cambiar ese texto por "Chau DOM" y viceversa.
- ¡Incluso puedes ponerle colores locos al título!
- También puedes jugar con imágenes: poner una, cambiarla por otra o hacerla más grande.

## Cosas técnicas importantes:
- **Responsive**: Se ve bien tanto en PC como en el celu.
- **Sin Alerts**: No usamos esas ventanitas molestas del navegador.
- **Humanizado**: El código tiene comentarios fáciles de leer, como si te los explicara un amigo.
- **Separado**: El HTML, el CSS y el JS están cada uno en su lugar, bien ordenado.

## ¿Cómo lo pruebo?
1. Entra a la carpeta `P1`.
2. Escribe `npm install` (si es la primera vez).
3. Escribe `node server.js`.
4. Abre `http://localhost:3001` en tu navegador.

¡Espero que te guste!
